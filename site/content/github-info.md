## Recent GitHub Blog and Changelog stories worth watching

- **[Remediate Code Quality findings with agentic autofix](https://github.blog/changelog/2026-09-09-remediate-code-quality-findings-with-agentic-autofix)** — Bulk-select up to 25 Code Quality findings and assign them to Copilot, which fixes them on a branch and opens a PR for review, cutting down manual cleanup toil.
- **[Enterprise managed permissions for GitHub Copilot agent operations](https://github.blog/changelog/2026-09-09-enterprise-managed-permissions-for-github-copilot-agent-operations)** — Admins can now centrally control which Copilot agent operations (shell commands, file edits, network domains) are blocked, require approval, or auto-proceed, useful for teams tightening agent guardrails.
- **[Block pull requests with exposed secrets from merging](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging)** — A new repository ruleset option stops PRs with detected secrets from merging, adding a hard gate alongside existing push protection.
- **[CodeQL 2.27.0 adds support for Linux ARM64](https://github.blog/changelog/2026-09-09-codeql-2-27-0-adds-support-for-linux-arm64)** — CodeQL now runs on Linux ARM64 and ships a new Rust security query plus expanded Java/Kotlin and C# coverage, handy for teams on ARM-based CI runners.
- **[GitHub Actions: Early September 2026 updates](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates)** — A bundle of Actions updates including a REST API for runner version deprecations and a new `vulnerability-alerts` permission for `GITHUB_TOKEN`, worth a look for anyone maintaining workflow files.
- **[Using the GitHub Copilot SDK for Java](https://github.blog/engineering/using-the-github-copilot-sdk-for-java/)** — A new Java SDK lets developers drive Copilot programmatically, directly relevant to teams building Copilot integrations into Java tooling.
